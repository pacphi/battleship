# Battleship P2P — Guide

Battleship P2P is a multiplayer Battleship game you play in your browser. Two players
connect directly to each other — there's no game server in the middle, and nothing to
download.

## Which one are you?

Pick the guide that matches what you want to do.

| You want to…                                       | Go here                                | Need a terminal? |
| -------------------------------------------------- | -------------------------------------- | ---------------- |
| 🎮 **Play** — a friend sent you a link or a code   | **[Playing the game](PLAYING.md)**     | No               |
| 🎉 **Host friends** — invite people to play online | **[Hosting a game](HOSTING.md)**       | A little         |
| 🚀 **Deploy it** — put it on a real website        | **[Deploying](DEPLOYING.md)**          | Yes              |
| 🛠️ **Work on the code** — develop or contribute    | **[Maintainer Guide](MAINTAINERS.md)** | Yes              |

### Not sure?

- **Someone gave you a web link** (like `https://something.zrok.io`) → you're a **Player**.
  Open it and read **[Playing](PLAYING.md)**.
- **You want to be the one who starts the game** so friends can join from their own
  computers → you're a **Host**. Read **[Hosting](HOSTING.md)**.
- **You want this game running at your own web address** for anyone to visit → you're
  **Deploying**. Read **[Deploying](DEPLOYING.md)**.

---

## The 10-second version

1. One person **hosts** (see [Hosting](HOSTING.md)) and shares a link.
2. Everyone opens the link, picks the same game mode, and swaps a **6-character code**.
3. **Click to fire.** Sink all 6 enemy ships to win.

That's it. The rest of this guide just fills in the details for whichever role you are.
